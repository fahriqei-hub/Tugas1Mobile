## Deskripsi Project
<p align="justify">
Tugas ini merupakan kegiatan pembuatan prototipe aplikasi mobile sederhana menggunakan MIT App Inventor dengan memanfaatkan komponen WebView untuk menampilkan halaman website kampus atau website berita teknologi secara langsung ketika aplikasi dijalankan. Dalam pengerjaannya, mahasiswa diwajibkan membuat akun GitHub sebagai sarana pengelolaan dan pengumpulan kode selama satu semester. Prototipe aplikasi juga harus dilengkapi minimal satu tombol navigasi, seperti Home atau Refresh, kemudian hasil akhirnya diekspor dalam format APK untuk didemonstrasikan pada pertemuan berikutnya. Tugas ini dikerjakan secara berkelompok dengan maksimal tiga orang, tetapi setiap mahasiswa tetap wajib mengumpulkan hasil pekerjaannya melalui akun GitHub masing-masing.
</p>
